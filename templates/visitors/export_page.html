Export Information

This tool allows you to export visitor log records to Excel format. You can either:

  • Select a specific date range and click "Export Selected Date Range", or
  • Click "Export Today's Records" to export only today's visitor logs

The exported Excel file will contain the following information:

  • Batch Number
  • Visitor's Name
  • Company
  • Visitor Type
  • ID Number
  • Check-in/out Times
  • Department Visited
  • Visit Purpose
  • Security Guard
  • Badge Status
